안심마커 길잡이 PWA 빠른 테스트 안내

1. 이 폴더를 GitHub 저장소에 올리고 GitHub Pages를 켭니다.
   - Settings > Pages > Deploy from branch > main / root
   - 생성된 https://...github.io/... 주소를 스마트폰에서 엽니다.

2. markers.html을 열어 0~5번 마커를 출력합니다.
   - 처음에는 10~15cm 크기로 크게 출력하세요.
   - 벽, 문 옆, 침대 옆 등 카메라가 보기 좋은 위치에 붙이세요.

3. index.html에서 카메라 시작을 누릅니다.
   - 카메라 권한 허용
   - 마커를 0.5~2m 거리에서 비춥니다.
   - 인식되면 ID별 안내문이 음성으로 출력됩니다.

4. 주의
   - 스마트폰 카메라 접근은 HTTPS 또는 localhost가 필요합니다.
   - 이 버전은 실험용입니다. 실제 보행 안전을 보장하지 않습니다.
   - CDN을 통해 js-aruco 라이브러리를 불러옵니다. 첫 실행에는 인터넷 연결이 필요합니다.
